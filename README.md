# Blackjack Ledger

A premium, mobile-first casino session tracker.

## Run it
Open `index.html` in a modern browser, or publish the folder with GitHub Pages.

## Features
- Log casino, date, any number of buy-in transactions, cash-out and notes.
- Automatic session profit/loss and lifetime P&L.
- Win percentage, return per £1 of buy-ins, average win and average loss.
- Casino rankings, recent sessions and cumulative P&L chart.
- Edit/delete entries and export a JSON backup.
- Entries persist in this browser on this device using localStorage.

## Important storage note
Data stays in the browser on this device. Clearing browser/site data or using a different browser/device can remove or separate the ledger. Use the export button regularly to save a backup. This is not cloud-synced.
